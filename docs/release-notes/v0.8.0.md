## What's new

- **No folders needed, and no Zidoos needed.** Resume Relay now finds the same file on Plex, Jellyfin and the Zidoos
  by the end of its path (`Arrival (2016)/Arrival (2016).mkv`), wherever each one keeps it. So Progress Reset and Watch
  Sync work with Plex alone, Jellyfin alone, or Plex and Jellyfin together, and stops and watched marks are copied
  between Plex and Jellyfin users with no folders set up.
  - Names that could be anything (`Season 01/S01E01.mkv` alone) are never matched by themselves: the show's folder
    is used too.
  - Folders on the Plex and Jellyfin cards are now optional. Ones you already set up keep working exactly as before;
    files outside them are matched automatically.
  - **Compare two players** on the Watch Sync tab shows how two players' files line up: how many both have, which
    ones only one has, and files with the same name in a different folder (a folder on the Plex or Jellyfin card fixes
    those).
- **Live Poster:** while a Now Showing video is being made, the slideshow keeps playing; the screen switches only once
  it's ready (no more empty background).
- **Live Poster:** the encoder line says plainly what makes the videos: Intel Quick Sync, NVIDIA or AMD video hardware,
  or software (slower), and why.
- **Live Poster:** the screen page's address in "Add a screen" is a link.
- **Watch-only now covers the Watch Sync tab too.** With Copying off, its buttons (a player's cell, Set on all, a whole
  show) change nothing on the players; they say what they would do, on the page and on the Activity tab. (They used to
  write anyway.)
- **Live Poster:** changing a screen's card (its sets, Feature Presentation, mount, resolution or format, or Rebuild)
  stops the videos only that screen was still waiting for, and its new slideshow starts right away instead of after the
  old one.
- **Live Poster:** a slideshow of one poster (a Feature Presentation by itself, say) has no fade from or to black; it's
  that slide, joined end to end.
- **Live Poster:** a browser screen removed in Resume Relay goes back to its pairing code on black (the slideshow no
  longer keeps playing behind it).
- **Live Poster:** **Remove title** next to Select a title on a screen's card takes the screen's Feature Presentation off.
- Settings → Rating badges: each badge keeps its name (IMDb, TMDB) next to the picture you chose, like Activity badges, so
  it's clear which rating a picture is for.
- **Highly Acclaimed no longer uses Jellyfin's ratings**, only IMDb's (or TMDB's, when there's no IMDb rating) from
  Plex or a Zidoo. Some of Jellyfin's were nonsense.
- Fixed: Progress Reset could briefly fail to load ("Collection was modified") while the players were being read.
- **Kaleidescape** (Live Poster only): Scan network finds Kaleidescape players (or add one by its IP address), and a
  Live Poster screen can follow one. When it plays a movie, the screen shows Now Showing with the Kaleidescape's own
  cover. Its card on the Players tab (in blue-grey) shows the movie and where it is.
  - A Kaleidescape plays its own copies of movies, not your files, and can't be given a resume point, so nothing is
    copied to or from it. It isn't on Progress Reset or Watch Sync.
  - Its stops (after at least a minute) are noted on the Activity tab and go into Recently Watched.
  - The movies Resume Relay has seen it play can be a screen's Feature Presentation. (A Kaleidescape can't list its
    whole library, and keeps no review scores, so it doesn't add to Highly Acclaimed.)
  - Its own activity badge picture can be set in Settings → App → Activity badges.
  - Built from Kaleidescape's published control protocol without a player to test on. If yours doesn't show up or
    misbehaves, please say so on Discord.
- Progress Reset and Watch Sync are greyed out until a Zidoo, Plex or Jellyfin player is added; Live Poster until any
  player is.
- Zidoo player cards show the Zidoo badge next to the power button, like the Plex and Jellyfin cards.
- Fixed: with Copying off (watch-only), the watched-marks check still copied watched marks between players. It now
  only notes on the Activity tab what it would copy, like stop copying does.
- Roku app: tells the Roku when its first screen is ready (needed for the Roku Channel Store).
- Fixed (also in 0.7.1): Plex's "None of the server's addresses answered from this computer", common in Docker on a
  NAS. plex.tv gives a server's home addresses as `plex.direct` names, which many routers and DNS filters refuse to
  look up (DNS rebinding protection). Each home address is now also tried as a plain IP address. If none answers, the
  message (and the Activity tab) lists every address tried and why it failed. In Plex, Settings → Network → Secure
  connections must be Preferred (the default), not Required.
