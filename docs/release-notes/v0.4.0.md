**Plex support:** add Plex users as players, so resume points and watched marks sync between your Zidoos and Plex in both directions. Also two new tabs: **Progress Reset** shows every file you've started on each player and resets one file or a whole TV show everywhere; **Watch Sync** shows where each file is marked watched and lets you change it per player.

## Downloads

| | File |
|---|---|
| **Windows 10 / 11** | `ResumeRelay-0.4.0-windows.exe`: a single file with nothing else to install |
| **Ubuntu 22.04 / 24.04 / 26.04** | `resume-relay-0.4.0-linux.tar.gz`: a background service, ideal for an always-on PC or server |
| **Docker / NAS** (Synology, uGreen and others) | `ghcr.io/ckenisell/resume-relay:0.4.0` (or `:latest`): no download needed, your NAS fetches it. See [Docker on a NAS](#docker-on-a-nas) below |

Upgrading keeps your players, names and settings. On Windows, quit the old version from the tray
and run the new file. On Linux, unpack and run `./install.sh` again.

## What's new

- **Plex users as players** (set up on a new **Plex** card in **Settings**; the Plex users then appear as cards on the Players tab):
  - **Sign in with Plex:** the card shows a 4-character code to enter at **plex.tv/link** on any device signed in to
    Plex. Your Plex password never goes through Resume Relay. Your Plex server is then found by itself (if the
    account has several, pick one).
  - **Folders:** Plex and the Zidoos reach the same files by different paths, for example `/shares/Entertainment` on
    the Plex server and `smb://10.0.0.56/Entertainment` on the Zidoos. Once a Zidoo has played something Plex also
    has, the card fills this in for you. **Test** shows how many Plex files the folders cover and checks a few of them
    against a Zidoo.
  - **Plex users:** add the server's owner and any Plex Home users (with their PIN if they have one). Each becomes a
    player card with what they're playing, and a column on Progress Reset and Watch Sync.
  - **Zidoo → Plex:** a stop on a Zidoo sets the same resume point for each Plex user. Finishing marks it played in
    Plex; a stop at 0:00 or a reset marks it unplayed.
  - **Plex → Zidoos:** a stop in any Plex app is copied to every Zidoo (and the other Plex users) at the position Plex
    saved. Finishing in Plex (by default Plex counts about 90% as finished) marks it watched on the Zidoos.
  - **Reset Progress**, **Reset TV Show** and **Watch Sync** work on Plex users too.
  - If Plex doesn't keep a very early resume point (a stop in the first minute), that copy is skipped for Plex and the
    chip says so.
- **Copy progress by dragging (Progress Reset tab):** drag a player's progress (its bar, percentage and times) onto
  another player's column in the same row. The copy waits there, outlined, with **×** to take it back; drag as many as
  you like across any titles, then press **Apply** (top right) to copy them all. Each file gets an Activity card from
  the player it was copied from. Dragging "not started" resets the file there; dragging a watched file marks it
  watched.
- **Sorting by title ignores "The", "A" and "An"** on Progress Reset and Watch Sync ("The Sopranos" sorts under S).
- **The top bar stays put:** the title, the copying switch and the tabs stay at the top while the page scrolls.
- **Copying is now a switch** (top right, on phones too): green **Copying**, or amber **Watch-only**. Turning it off
  asks first. On phones the top bar is compact.
- **Zidoo / Plex badge on each player's column** on Progress Reset and Watch Sync.
- **Faster reads on Progress Reset and Watch Sync:** each player is asked four titles at a time (was three), titles
  and collections that didn't answer are asked again after shorter waits, and a collection that answered and really is
  empty is no longer waited on. Titles and collections that don't answer are still asked again, as before.
- **TV shows on Progress Reset and Watch Sync:** a show's **Reset TV Show** button now sits in the Reset column, in
  line with its episodes' Reset buttons. On Watch Sync, a show's heading has **Watched All** and **Unwatched All**,
  which mark every episode of the show on every ticked player (counted and confirmed first).
- **Activity badges:** every Activity card shows whether the stop happened on a Zidoo or on Plex, and each player chip
  shows which kind it is. In **Settings → Activity badges** you can replace either badge with your own small image;
  it's kept in Resume Relay's data folder on that computer.
- **Progress Reset tab** (between Activity and the gear icon), modelled on Z-Keeper's *In progress* page:
  - Tick the players to show, then press **Read players**. Each player's library is read title by title
    (about a minute or two per player). Every file with a resume point on any ticked player is listed.
  - **Show** all files, only those with *different progress between players*, or only those with the
    *same progress on all players* (within 2 seconds; *not started* counts as 0:00, and players without
    the file are left out). Sort by **Title** or **Last watched**.
  - **Title** shows the full file name for movies, and *Show - S01E04: Episode name* for TV episodes.
  - One column per player: a progress bar, the percentage, *position of length*, and the date it was
    last watched, with ✓ when the player has it marked watched. *not started* when the player has the
    file but no progress, *not in library* when it doesn't have the file.
  - **Reset** clears that file's progress on every player, after the same Cancel / Continue question as
    the Activity tab, and adds a "Reset from Resume Relay" card to Activity.
  - **Reset TV Show** (on episode rows) clears every episode of every season of that show, on every
    player, and adds one card with the number of episodes reset on each player.
  - Players that are off get the reset when they come back. Rows leave the list as their resets land.
- **Watch Sync tab** (next to Progress Reset; one Read players serves both tabs):
  - Tick the players to compare. **Show** what's *different between players* (the default), *watched on
    any player*, *not watched anywhere*, *missing on some players* (a file one player has and another
    doesn't), or *all files*, sorted by title or last watched, with a search box.
  - Long lists come in pages of 500, with **‹ Previous / Next ›** (and first / last) above and below the
    table, so every file can be reached.
  - Each player's cell is a button: **✓ Watched** or **Not watched**, with the date it was last watched.
    Click it to change that one player. **Set on all** marks a file watched or unwatched on every ticked
    player.
  - Marking watched uses Home Theater's own "mark as watched", which also removes that player's resume
    point, so you're asked first whenever a resume point would be lost. Marking unwatched keeps the
    resume point. Every change is read back from the player before the cell updates.
- **Movies inside collections are read reliably.** Collections are opened the way Z-Keeper opens them (by
  the tile's own id), and "my collections" you made yourself are read too. Before, a movie inside a
  collection could show as *not in library* on some players.
- **Reads no longer lose titles when a player is busy.** A movie or season the player doesn't answer for
  is asked again, slowly, after the first pass, instead of quietly coming back empty (which made its files
  show as *not in library* and file counts change from one read to the next). Anything still unanswered
  keeps its last known state, and the player's column says "N titles couldn't be read".
- **Troubleshooting page:** `http://<this-computer>:8090/api/progress/diagnostics?q=<part of a title>`
  shows what each player's library listing held and how every collection and series was opened. At the
  top it compares the players' library walls and lists any poster one player shows and another doesn't.
- **Phones:** on narrow screens, Progress Reset and Watch Sync show cards instead of a wide table: one
  card per movie, and one card per TV show with the show's name and **Reset TV Show** at the top and each
  episode below it (its own **Reset** beside its name, then one line per player). The controls stack, and
  all five tabs fit across the screen.
- **TV shows are grouped on desktop too:** in both tables, each show gets a heading row (with **Reset TV
  Show** on Progress Reset) and its episodes are listed beneath it, each with its own **Reset**.
- **Power button:** turning a player off keeps the orange ring spinning until the player has really
  gone off, instead of briefly turning green again first.
- **Launch HT:** the button spins until the Home Theater app is actually running (up to 30 seconds), then
  a short notice says *"The Home Theater app on [player] has successfully started."*
- **Fix:** a Reset Progress could be dropped for a player that was off and still had an older copy of the
  same file waiting. Resets now always replace older waiting copies.

## Docker on a NAS

Resume Relay also runs in Docker, for example on a **Synology** (DSM 7.2 or
later, with Container Manager) or **uGreen** (UGOS Pro, with the Docker app) NAS, as well as QNAP,
Unraid and TrueNAS. It's the same program as the downloads above, for Intel/AMD and ARM (64-bit).

On Synology: **Container Manager → Project → Create**. On uGreen: **Docker → Project → Create**.
Paste this as the compose file, deploy it, then open `http://<your-nas-address>:8090`:

```yaml
services:
  resume-relay:
    image: ghcr.io/ckenisell/resume-relay:latest
    container_name: resume-relay
    network_mode: host
    restart: unless-stopped
    environment:
      - RESUMERELAY_PORT=8090
    volumes:
      - ./data:/data
```

Keep `network_mode: host`: without it, **Scan network** finds nothing and the **power button**
can't turn players on. Full step-by-step instructions, including updating, are on the
[Resume Relay home page](https://github.com/ckenisell/resume-relay#docker-and-nas-synology-ugreen-and-others).

## Requirements

- **Windows 10 / 11**, **Ubuntu 22.04 / 24.04 / 26.04**, or **Docker** (Synology DSM 7.2+,
  uGreen UGOS Pro, QNAP, Unraid, TrueNAS; Intel/AMD or ARM 64-bit, with host networking)
- Zidoo players with **Home Theater v5.1.11 (code 5111) or newer**
- Your video files on a network share (SMB or NFS) that all players use, so each file has the
  same path everywhere

Run only **one** copy of Resume Relay per home, on a computer that stays on while you watch.

The Zidoo API knowledge behind this project comes largely from the HT5 API guide at
[z-keeper.com](https://z-keeper.com/learn/ht5-api-guide). Not affiliated with Zidoo.
