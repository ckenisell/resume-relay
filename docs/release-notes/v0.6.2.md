## What's new

- **Try a demo** in the Roku and Android screen apps: a slideshow of invented posters on the built-in marquee
  backgrounds, for trying the app before Resume Relay is set up. It's on the screen that asks for Resume Relay's address,
  next to the pairing code, and in the OK menu.
- **The Android app is now signed with Resume Relay's own key.** If you installed an earlier Android screen app,
  uninstall it once before installing this one (and add the screen again with its new code). Later updates install
  over it as usual.
- A [privacy policy](https://github.com/ckenisell/resume-relay/blob/main/docs/privacy.md) for the screen apps: they
  collect nothing.
