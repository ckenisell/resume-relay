## What's fixed

- **Plex: "None of the server's addresses answered from this computer."** plex.tv gives a Plex server's home
  addresses as special `plex.direct` names, and many routers and DNS filters refuse to look those names up (a
  security feature called DNS rebinding protection). That's common when Resume Relay runs in Docker on a NAS. It now
  also tries each home address as a plain IP address, which needs no lookup.
  - If no address answers, the message now lists every address it tried and why each one failed, and the same list
    goes into the Activity tab.
  - Plex must allow plain connections at home: in Plex, **Settings → Network → Secure connections** should be
    **Preferred** (Plex's default), not **Required**. The message says so when that's the problem.
- **Watch-only:** with Copying off, the watched-marks check still copied watched marks between players. It now only
  notes on the Activity tab what it would copy, like stop copying does.

## Docker on a NAS

- **Synology:** create the **data** folder inside your **resume-relay** project folder before starting the project.
  Container Manager doesn't create it, and the project stops with "Bind mount failed".
- **Unraid and others:** the folder on your NAS must be mapped to the container path **`/data`** exactly. Mapped
  anywhere else (Unraid often suggests `/config`), your players and settings are lost on the next update.

The README has step-by-step instructions, including the DSM firewall rules.
