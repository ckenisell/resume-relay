**Live Poster: a digital movie poster outside each room, with no extra hardware.** A TV, stick or tablet shows the poster of what that room is playing, over your own background, and a slideshow when nothing is.

## Downloads

| | File |
|---|---|
| **Windows 10 / 11** | `ResumeRelay-0.6.0-windows.exe`: a single file with nothing else to install |
| **Ubuntu 22.04 / 24.04 / 26.04** | `resume-relay-0.6.0-linux.tar.gz`: a background service, ideal for an always-on PC or server |
| **Docker / NAS** (Synology, uGreen and others) | `ghcr.io/ckenisell/resume-relay:0.6.0` (or `:latest`): no download needed, your NAS fetches it. See [Docker on a NAS](#docker-on-a-nas) below |
| **Screen app: Android** (Fire TV, Google TV, phones, tablets) | `ResumeRelay-Screen-0.6.0-android.apk` |
| **Screen app: Roku** | `ResumeRelay-Screen-0.6.0-roku.zip` (installed from the Roku's developer page for now) |

Upgrading keeps your players, names and settings. On Windows, quit the old version from the tray
and run the new file. On Linux, unpack and run `./install.sh` again (it now also installs ffmpeg).

## What's new

- **Live Poster tab** (before the gear):
  - **Screens:** install the screen app (or open `http://<this computer>:8090/screen` in a browser), and add the screen
    with the 4-digit code it shows. For each screen: which players it follows (Zidoos and Plex users, any number), how
    it's mounted (a TV on its side, top left or right, or upright), 4K or 1080p, a **Test picture**, and a live
    preview of what it shows.
  - **Now Playing:** when one of a screen's players plays something (or is paused on it), its poster goes up over the
    Now Playing background. After a stop it stays up for 30 seconds (adjustable).
  - **Slideshow** when nothing is playing: **Coming Soon** (posters you upload, in your order), **Recently Watched**
    (the last 10 titles stopped on the screen's players) and **Highly Acclaimed** (movies and series rated 8.0 or more;
    10 picked at random each round). Ratings come from Plex when it's set up; without Plex, from the Zidoo: IMDb for
    movies, TMDB for series (the HT app keeps no IMDb rating for series). Each set has an on/off switch and its own background; they take turns,
    15 seconds a poster (adjustable), fading in and out.
  - **Backgrounds:** upload 2160×3840 images or 10–20 second MP4 loops. Placeholders are included until you add your
    own.
  - **Posters:** from the movie's or show's folder first (your own artwork, Kodi naming), then Plex, then the Zidoo.
- **True 4K:** stick and TV apps draw their own pictures at 1080p but play video at 4K, so Resume Relay makes each
  picture into a short 4K video with ffmpeg, on Intel Quick Sync / VA-API when available (it leaves the processor to
  Plex), at the lowest priority, and keeps each one so it's only made once. They're kept in Resume Relay's data folder
  (`live/renders`), up to 20 GB; the least recently used go first.
- **Screen apps:** Android (Fire TV, Google TV, phones, tablets) and Roku. They find Resume Relay by themselves (or you
  type its address), keep the screen awake, and play the 4K video. Press OK on the remote for options.
- **Show files** on every batch card, and Catch Up / Copy all no longer re-mark files that were already watched (from
  0.5.0-beta.3).

## Docker on a NAS

Resume Relay also runs in Docker, for example on a **Synology** (DSM 7.2 or
later, with Container Manager) or **uGreen** (UGOS Pro, with the Docker app) NAS, as well as QNAP,
Unraid and TrueNAS. It's the same program as the downloads above, for Intel/AMD and ARM (64-bit).

On Synology: **Container Manager → Project → Create**. On uGreen: **Docker → Project → Create**.
Paste this as the compose file, deploy it, then open `http://<your-nas-address>:8090`:

```yaml
services:
  resume-relay:
    image: ghcr.io/ckenisell/resume-relay:latest
    container_name: resume-relay
    network_mode: host
    restart: unless-stopped
    environment:
      - RESUMERELAY_PORT=8090
    devices:
      - /dev/dri:/dev/dri   # Live Poster: encode on the video hardware (leave out if the NAS has none)
    volumes:
      - ./data:/data
```

Keep `network_mode: host`: without it, **Scan network** finds nothing, the **power button**
can't turn players on, and screen apps can't find Resume Relay. Full step-by-step instructions, including updating,
are on the [Resume Relay home page](https://github.com/ckenisell/resume-relay#docker-and-nas-synology-ugreen-and-others).

## Requirements

- **Windows 10 / 11**, **Ubuntu 22.04 / 24.04 / 26.04**, or **Docker** (Synology DSM 7.2+,
  uGreen UGOS Pro, QNAP, Unraid, TrueNAS; Intel/AMD or ARM 64-bit, with host networking)
- Zidoo players with **Home Theater v5.1.11 (code 5111) or newer**
- Your video files on a network share (SMB or NFS) that all players use, so each file has the
  same path everywhere
- Live Poster: ffmpeg (installed for you on Ubuntu and in Docker; one click on Windows), and a screen that can play
  4K H.264 video for 4K (1080p otherwise). Avoid TVs that can get burn-in (OLED, plasma).

Run only **one** copy of Resume Relay per home, on a computer that stays on while you watch.

The Zidoo API knowledge behind this project comes largely from the HT5 API guide at
[z-keeper.com](https://z-keeper.com/learn/ht5-api-guide). Not affiliated with Zidoo.
