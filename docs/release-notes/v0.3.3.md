Two new tabs: **Progress Reset** shows every file you've started on each player and resets one file or a whole TV show everywhere; **Watch Sync** shows where each file is marked watched and lets you change it per player.

## Downloads

| | File |
|---|---|
| **Windows 10 / 11** | `ResumeRelay-0.3.3-windows.exe`: a single file with nothing else to install |
| **Ubuntu 22.04 / 24.04 / 26.04** | `resume-relay-0.3.3-linux.tar.gz`: a background service, ideal for an always-on PC or server |
| **Docker / NAS** (Synology, uGreen and others) | `ghcr.io/ckenisell/resume-relay:0.3.3` (or `:latest`): no download needed, your NAS fetches it. See [Docker on a NAS](#docker-on-a-nas) below |

Upgrading keeps your players, names and settings. On Windows, quit the old version from the tray
and run the new file. On Linux, unpack and run `./install.sh` again.

## What's new

- **Progress Reset tab** (between Activity and the gear icon), modelled on Z-Keeper's *In progress* page:
  - Tick the players to show, then press **Read players**. Each player's library is read title by title
    (about a minute or two per player). Every file with a resume point on any ticked player is listed.
  - **Show** all files, only those with *different progress between players*, or only those with the
    *same progress on all players* (within 2 seconds; *not started* counts as 0:00, and players without
    the file are left out). Sort by **Title** or **Last watched**.
  - **Title** shows the full file name for movies, and *Show - S01E04: Episode name* for TV episodes.
  - One column per player: a progress bar, the percentage, *position of length*, and the date it was
    last watched, with ✓ when the player has it marked watched. *not started* when the player has the
    file but no progress, *not in library* when it doesn't have the file.
  - **Reset** clears that file's progress on every player, after the same Cancel / Continue question as
    the Activity tab, and adds a "Reset from Resume Relay" card to Activity.
  - **Reset TV Show** (on episode rows) clears every episode of every season of that show, on every
    player, and adds one card with the number of episodes reset on each player.
  - Players that are off get the reset when they come back. Rows leave the list as their resets land.
- **Watch Sync tab** (next to Progress Reset; one Read players serves both tabs):
  - Tick the players to compare. **Show** what's *different between players* (the default), *watched on
    any player*, *not watched anywhere*, *missing on some players* (a file one player has and another
    doesn't), or *all files*, sorted by title or last watched, with a search box.
  - Long lists come in pages of 500, with **‹ Previous / Next ›** (and first / last) above and below the
    table, so every file can be reached.
  - Each player's cell is a button: **✓ Watched** or **Not watched**, with the date it was last watched.
    Click it to change that one player. **Set on all** marks a file watched or unwatched on every ticked
    player.
  - Marking watched uses Home Theater's own "mark as watched", which also removes that player's resume
    point, so you're asked first whenever a resume point would be lost. Marking unwatched keeps the
    resume point. Every change is read back from the player before the cell updates.
- **Movies inside collections are read reliably.** Collections are opened the way Z-Keeper opens them (by
  the tile's own id), and "my collections" you made yourself are read too. Before, a movie inside a
  collection could show as *not in library* on some players.
- **Reads no longer lose titles when a player is busy.** A movie or season the player doesn't answer for
  is asked again, slowly, after the first pass, instead of quietly coming back empty (which made its files
  show as *not in library* and file counts change from one read to the next). Anything still unanswered
  keeps its last known state, and the player's column says "N titles couldn't be read".
- **Troubleshooting page:** `http://<this-computer>:8090/api/progress/diagnostics?q=<part of a title>`
  shows what each player's library listing held and how every collection and series was opened.
- **Fix:** a Reset Progress could be dropped for a player that was off and still had an older copy of the
  same file waiting. Resets now always replace older waiting copies.

## Docker on a NAS

Resume Relay also runs in Docker, for example on a **Synology** (DSM 7.2 or
later, with Container Manager) or **uGreen** (UGOS Pro, with the Docker app) NAS, as well as QNAP,
Unraid and TrueNAS. It's the same program as the downloads above, for Intel/AMD and ARM (64-bit).

On Synology: **Container Manager → Project → Create**. On uGreen: **Docker → Project → Create**.
Paste this as the compose file, deploy it, then open `http://<your-nas-address>:8090`:

```yaml
services:
  resume-relay:
    image: ghcr.io/ckenisell/resume-relay:latest
    container_name: resume-relay
    network_mode: host
    restart: unless-stopped
    environment:
      - RESUMERELAY_PORT=8090
    volumes:
      - ./data:/data
```

Keep `network_mode: host`: without it, **Scan network** finds nothing and the **power button**
can't turn players on. Full step-by-step instructions, including updating, are on the
[Resume Relay home page](https://github.com/ckenisell/resume-relay#docker-and-nas-synology-ugreen-and-others).

## Requirements

- **Windows 10 / 11**, **Ubuntu 22.04 / 24.04 / 26.04**, or **Docker** (Synology DSM 7.2+,
  uGreen UGOS Pro, QNAP, Unraid, TrueNAS; Intel/AMD or ARM 64-bit, with host networking)
- Zidoo players with **Home Theater v5.1.11 (code 5111) or newer**
- Your video files on a network share (SMB or NFS) that all players use, so each file has the
  same path everywhere

Run only **one** copy of Resume Relay per home, on a computer that stays on while you watch.

The Zidoo API knowledge behind this project comes largely from the HT5 API guide at
[z-keeper.com](https://z-keeper.com/learn/ht5-api-guide). Not affiliated with Zidoo.
