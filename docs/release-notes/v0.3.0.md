A new look, power buttons for every player, and resume points that land on the exact second.

## Downloads

| | File |
|---|---|
| **Windows 10 / 11** | `ResumeRelay-0.3.0-windows.exe`: a single file with nothing else to install |
| **Ubuntu 22.04 / 24.04 / 26.04** | `resume-relay-0.3.0-linux.tar.gz`: a background service, ideal for an always-on PC or server |

Upgrading keeps your players, names and settings. On Windows, quit the old version from the tray
and run the new file. On Linux, unpack and run `./install.sh` again.

## What's new

- **Tabs.** Players, Activity and Settings (the gear icon) each have their own tab. The Players
  tab shows how many copies are waiting, and the app remembers which tab you had open.
- **Room cards.** Each player is a card. While it's playing you see the poster, title, episode
  (S01E04) and position. A player whose Home Theater app is closed says so. Copies waiting for a
  player are listed on its own card, each with a Discard button.
- **Power buttons, like Z-Keeper's.** Red means off: click to turn the player on. An orange ring
  spins while it boots. Green means on: click to turn it off (it asks first if something is
  playing). Turning on uses Wake-on-LAN, then opens the Home Theater app; right-click the red
  button to turn on without opening it.
- **Launch HT** sits next to the power button while a player is on, and opens its Home Theater app.
- **Activity cards.** Each stop is one card with the poster (the season poster for episodes),
  where you stopped, and a chip for every other player: ✓ copied, ◷ waiting (it turns to ✓ when
  the copy lands), – skipped, ✕ failed. Messages like "Bedroom is back online" sit between the
  cards, grouped by day.
- **Exact stop time.** Resume Relay now copies the position the player itself saved when you
  pressed stop. Before, it copied the last position it had seen, which could be up to 3 seconds
  earlier.

## Turning players on

Wake-on-LAN only works on a player that is in standby (not unplugged), on a **wired**
connection, with network wake-up allowed in its settings. Turning off works on any player that
is on.

## Requirements

- Zidoo players with **Home Theater v5.1.11 (code 5111) or newer**
- Your video files on a network share (SMB or NFS) that all players use, so each file has the
  same path everywhere

Run only **one** copy of Resume Relay per home, on a computer that stays on while you watch.
