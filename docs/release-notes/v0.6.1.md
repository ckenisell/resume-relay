**Fixes for watched marks and a clearer Live Poster while slideshows are made.**

## Downloads

| | File |
|---|---|
| **Windows 10 / 11** | `ResumeRelay-0.6.1-windows.exe`: a single file with nothing else to install |
| **Ubuntu 22.04 / 24.04 / 26.04** | `resume-relay-0.6.1-linux.tar.gz`: a background service, ideal for an always-on PC or server |
| **Docker / NAS** (Synology, uGreen and others) | `ghcr.io/ckenisell/resume-relay:0.6.1` (or `:latest`) |
| **Screen app: Android** (Fire TV, Google TV, phones, tablets) | `ResumeRelay-Screen-0.6.1-android.apk` |
| **Screen app: Roku** | `ResumeRelay-Screen-0.6.1-roku.zip` (installed from the Roku's developer page for now) |

Upgrading keeps your players, names and settings. Update the screen apps too, for the new Loading screen.

## What's fixed

- **Watched marks set in the HT app are copied again.** A mark set on a player was missed when something else read the
  players in between (Watch Sync or Progress Reset's **Read players**). Now every read notes the marks that changed, and
  the check copies all of them.

## Live Poster

- **Loading screen:** while a screen's first slideshow is being made, the screen shows **Loading…** with a progress bar,
  turned the same way as the posters (instead of an empty background). After **Rebuild slideshow**, the slideshow
  that's up keeps playing until the new one is ready.
- **Two progress bars on the screen's card:** step 1 makes each poster into a slide, step 2 makes the dissolves between
  them and joins everything into one video, with about how long is left. The counts only go up, and they keep updating
  while you're typing in the card.
- **"Screen app: playing"** now shows only once the screen is really playing the video it was given.
- **Test picture:** "UP" in the arrowhead and **RESUME RELAY** below the arrow.
