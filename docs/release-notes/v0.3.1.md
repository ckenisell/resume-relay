Stopping at 0:00 now resets a title on every player.

## Downloads

| | File |
|---|---|
| **Windows 10 / 11** | `ResumeRelay-0.3.1-windows.exe`: a single file with nothing else to install |
| **Ubuntu 22.04 / 24.04 / 26.04** | `resume-relay-0.3.1-linux.tar.gz`: a background service, ideal for an always-on PC or server |

Upgrading keeps your players, names and settings. On Windows, quit the old version from the tray
and run the new file. On Linux, unpack and run `./install.sh` again.

## What's new

- **Stopping at 0:00 resets the title everywhere.** Start something from the beginning and stop it
  straight away, and the other players clear their bookmark and watched mark for it too, so it
  starts from the beginning in every room. Before, a stop at 0:00 was ignored. The Activity card
  says "progress reset".
- **The version shown in the app is now the exact build**, including test builds (for example
  0.3.1-beta.1), and each download's file name carries that label too.

## Requirements

- Zidoo players with **Home Theater v5.1.11 (code 5111) or newer**
- Your video files on a network share (SMB or NFS) that all players use, so each file has the
  same path everywhere

Run only **one** copy of Resume Relay per home, on a computer that stays on while you watch.
