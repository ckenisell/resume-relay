Stop a movie or episode on one Zidoo, walk to another room, and press **Resume**.

Resume Relay watches every Zidoo player on your network. A few seconds after one stops, it copies
that file's resume point to all the others. You don't need a watch list or any setup per title:
anything you watch is copied.

## Downloads

| | File |
|---|---|
| **Windows 10 / 11** | `ResumeRelay-0.2.0-windows.exe`: a single file with nothing else to install |
| **Ubuntu 22.04 / 24.04 / 26.04** | `resume-relay-0.2.0-linux.tar.gz`: a background service, ideal for an always-on PC or server |

Run only **one** copy of Resume Relay per home, on a computer that stays on while you watch. Two
copies would each copy every stop.

## What it does

- **Copies resume points between rooms automatically.** Within seconds of stopping, the same file
  on every other player resumes where you left off. TV episodes, movies and extras are all matched
  exactly by file path.
- **The latest stop always wins.** It replaces the other players' bookmark for that file, even if
  theirs is further along. Short stops count too.
- **Auto-play to the next episode** counts as finishing the previous one, which is marked watched
  on the other players.
- **Sleeping players catch up.** A player that's off, asleep, or on without its Home Theater app
  open gets its copies as soon as it's ready. Waiting copies are listed in the app and kept for 14 days.
- **Every write is checked.** Before writing, it confirms the player's entry really is that file.
  After writing, it reads the position back, because some Home Theater builds report errors for
  writes that worked.
- **Finds your players for you.** Scan the network, then give each player a room name. Players
  are recognised by their hardware address, so a name stays put even if your router gives the
  player a new IP.
- **Watch-only mode** on first run: it logs what it *would* copy until you press **Start copying**.

## Windows app

- Runs in its own window. Closing the window keeps it running in the tray; right-click the tray
  icon to quit.
- **Starts with Windows by default**, straight to the tray. Untick it in Settings or the tray menu.
- The first time you run it, Windows may show *"Windows protected your PC"* because the app isn't
  code-signed yet. Click **More info → Run anyway**. If Windows asks about network access, allow
  **Private networks**.
- The page can also be opened from a phone on the same network at `http://<pc-address>:8090`.

## Linux service

Unpack, then run `./install.sh`. It installs the .NET runtime from Ubuntu's own archive if
needed and sets Resume Relay up to start with the computer. Upgrading keeps your players and
settings. Full instructions are in the `README.md` inside.

## Requirements

- Zidoo players with **Home Theater 5.1.03 or newer**
- Your video files on a network share (SMB or NFS) that all players use, so each file has the
  same path everywhere

## Known limitations

- Resume points are copied when playback stops. Anything watched while Resume Relay itself isn't
  running isn't copied afterwards.
- Files played from a USB drive or a player's internal disk can't be matched across players, so
  they aren't copied.
