Resume RelayStop in one room, resume in another.

Players

Click a name to rename it. Players are recognised by their network hardware address, so a name stays with the right player even if your router gives it a new IP.

Activity

Every stop and where it was copied, newest first.

Progress Reset

Everything you have started and not reset, on the players you tick: each file with a resume point, and how far in it is on each player. It's read live from the players, title by title, which takes a minute or two per player. Nothing is changed on a player until you press a Reset button.

Watch Sync

Where each movie and episode is marked watched, on the players you tick. Click a player's cell to mark that file watched or not watched there, or use Set on all for every ticked player. Marking watched removes that player's resume point; marking unwatched keeps it. It uses the same read as Progress Reset.

Settings

Changes are saved as soon as you leave a box.
