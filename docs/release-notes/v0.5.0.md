**Copy everything at once, undo anything, and know when there is a new version.** Each player's column on Progress Reset and Watch Sync gets **Copy all**, every batch can be undone from its Activity card, the Activity tab gets filters, and Resume Relay tells you when an update is out.

## Downloads

| | File |
|---|---|
| **Windows 10 / 11** | `ResumeRelay-0.5.0-windows.exe`: a single file with nothing else to install |
| **Ubuntu 22.04 / 24.04 / 26.04** | `resume-relay-0.5.0-linux.tar.gz`: a background service, ideal for an always-on PC or server |
| **Docker / NAS** (Synology, uGreen and others) | `ghcr.io/ckenisell/resume-relay:0.5.0` (or `:latest`): no download needed, your NAS fetches it. See [Docker on a NAS](#docker-on-a-nas) below |

Upgrading keeps your players, names and settings. On Windows, quit the old version from the tray
and run the new file. On Linux, unpack and run `./install.sh` again.

## What's new

- **Copy all from a player's column** (Progress Reset and Watch Sync): under each player's name there's **Target**
  and **Copy all ⟶**. Tick Target on the players that should receive, then press Copy all on the one to copy from.
  - It covers **every file in the list as filtered**: the Show option and the search, across **all pages**. For
    example, Show "Different between players" then Copy all fixes every difference in one go.
  - It shows the counts and asks first. On Progress Reset, files the source player hasn't started are left out
    unless you tick "Also reset N files … hasn't started".
  - Progress copies go through the normal copy queue (players that are off get them later); watched marks run in the
    Watch Sync queue with a progress bar, Stop and Remove.
- **Undo:** every Copy all, Watched All / Unwatched All, and drag-and-Apply copy gets an **Undo** button on its Activity
  card, once its copies are done. It puts each file back the way each player had it before (resume point, watched
  mark, or nothing). Last-watched dates aren't restored.
- **One Activity card per batch**, not one per file: its chips count the files on each player
  ("270 done · 6 skipped").
- **Activity filters:** by player, Zidoo or Plex, **Failed only**, and a search.
- **Search on Progress Reset**, like Watch Sync's.
- **New version notice:** once a day Resume Relay checks GitHub for a newer version (nothing about you or your players
  is sent). A banner offers **What's new**, **How to update** (the exact steps for Windows, Ubuntu or Docker),
  **Remind me later** and **Skip this version**; a dot on the gear tab shows while an update is out. In Settings you can
  turn the check off, include beta versions, or check now.

## Docker on a NAS

Resume Relay also runs in Docker, for example on a **Synology** (DSM 7.2 or
later, with Container Manager) or **uGreen** (UGOS Pro, with the Docker app) NAS, as well as QNAP,
Unraid and TrueNAS. It's the same program as the downloads above, for Intel/AMD and ARM (64-bit).

On Synology: **Container Manager → Project → Create**. On uGreen: **Docker → Project → Create**.
Paste this as the compose file, deploy it, then open `http://<your-nas-address>:8090`:

```yaml
services:
  resume-relay:
    image: ghcr.io/ckenisell/resume-relay:latest
    container_name: resume-relay
    network_mode: host
    restart: unless-stopped
    environment:
      - RESUMERELAY_PORT=8090
    volumes:
      - ./data:/data
```

Keep `network_mode: host`: without it, **Scan network** finds nothing and the **power button**
can't turn players on. Full step-by-step instructions, including updating, are on the
[Resume Relay home page](https://github.com/ckenisell/resume-relay#docker-and-nas-synology-ugreen-and-others).

## Requirements

- **Windows 10 / 11**, **Ubuntu 22.04 / 24.04 / 26.04**, or **Docker** (Synology DSM 7.2+,
  uGreen UGOS Pro, QNAP, Unraid, TrueNAS; Intel/AMD or ARM 64-bit, with host networking)
- Zidoo players with **Home Theater v5.1.11 (code 5111) or newer**
- Your video files on a network share (SMB or NFS) that all players use, so each file has the
  same path everywhere

Run only **one** copy of Resume Relay per home, on a computer that stays on while you watch.
